CHIMERA

Video editing and measurement · local-first

CHIMERA composes short-form videos and measures them — its own output and reference material alike, along the same set of properties. Its TikTok integration exists to answer one question: which of those measured properties actually separate the videos that reached an audience from the ones that did not.

01

What it measures

Twenty-five properties per video, taken with the same instrument whether the file is the owner's own render or a reference clip.

Image
Cut rate, hook cuts, longest still, brightness, saturation, grain
Text
Subtitle height as a fraction of frame width, background contrast, legibility
Speech
Word count, speech fraction, words per second, sentences, questions, address
Sound
Loudness in LUFS, loudness range, true peak, tempo in BPM, clipping
02

What it does not do

CHIMERA produces no virality score. A single number on a scale would require weightings that nobody actually knows, and inventing them would dress a guess as a finding.

What it reports instead is measured quantities and whether a difference between two groups of videos survives a permutation test. Where the evidence does not carry a conclusion, it says so rather than filling the gap.

03

The TikTok integration

Three read-only permissions, requested from the owner's own account. No write permission of any kind is requested, so the application cannot post, edit, delete or comment.

user.info.basic Confirms which account a stored token belongs to, so measurements are not misattributed
user.info.stats Follower and video counts — the denominator reach is only interpretable against
video.list The owner's own videos with their public view, like, comment and share counts
Local by construction

There is no server. Authorisation uses OAuth 2.0 with PKCE, so no password ever reaches the application; tokens are written to a file on the owner's own machine and are sent nowhere but TikTok's own endpoints. No telemetry, no analytics, no third-party sharing.

04

Availability

CHIMERA is single-user software, run by its owner on their own machine. It is not offered as a hosted service, has no sign-up, and carries no fee. This page exists to document what the application is and which data it touches.
